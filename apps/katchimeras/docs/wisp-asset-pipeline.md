# Wisp asset pipeline

The Wisp pipeline mirrors the reviewed Egg Avatar workflow while keeping each Wisp a freestanding companion layer.

## Generate

Generate exactly one candidate on a perfectly uniform removable key background. Use the approved silhouette-family anchor, Baristabbit, Today runtime background, and Classic Egg in the authority order defined by the art bible. The prompt must restate the Wisp's catalog visual summary, palette, intrinsic motif, and exclusions.

Production prompt blocks:

1. Wisp identity and single motif.
2. Tiny scale, simple silhouette, face, and contained glow.
3. `katchimeras-wisp-cozy-toy-v1` materials and lighting.
4. Canonical centered square registration.
5. Flat key background and negative constraints.

## Matte and promote

1. Run BiRefNet General Use Heavy in the hosted production path. For built-in image generation, the approved local chroma-key helper is the review-stage equivalent.
2. Validate real alpha, transparent corners, plausible subject coverage, and no key fringe.
3. Save the archival PNG, 1024 px app WebP, and 256 px thumbnail WebP.
4. Generate the multi-context compatibility sheet.
5. Promote the catalog entry from `planned` to `ready`, increment its version when replacing art, update the manifest, and regenerate the literal Expo registry together.

Production paths:

- `assets/images/katchimeras/wisps/<id>.png`
- `assets/images/katchimeras/wisps/<id>.webp`
- `assets/images/katchimeras/wisps/thumbnails/<id>.webp`
- `assets/images/katchimeras/wisps/manifest.json`

Run `npm run test:wisps`, `npm run typecheck`, `npm run lint`, and `npm run assets:audit:check` after promotion.
