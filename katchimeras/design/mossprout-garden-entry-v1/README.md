# Mossprout Garden Entry v1

Production assets for replacing the world-space Merge board with a compact Garden destination.

- `mossprout-garden-hub-v2-chroma.png`: generated chroma source for the compact world island. It keeps the upper staging strip empty for dynamic tray stacks, closes the front edge, fences the sides/front, and replaces the central plaza with planting beds.
- `mossprout-garden-button-v1-chroma.png`: generated chroma source for the bottom-right Garden shortcut.
- `*-master.png`: transparent 1024px masters produced by the packaging script.

Art direction: strict match to `design/square-haven-v1/mossprout-main-environment-alpha-v5-hex-style.png`; orthographic cozy toy diorama, broad cushiony bevels, sparse detail, rounded ochre cliff modules, olive/lime foliage, and honey wood. The island reserves a clean empty rear strip for dynamic chair, character, tray, and item layers. No text is baked into the button.

Run `python scripts/package-mossprout-garden-entry.py` after replacing either chroma source.
