## Art set

Sunrise trays, dawn bell timepieces, sunrise crests, morning totes and radiant garden doorways.

- Sheet A uses the authored family-specific ladders plus the three runtime goal tiers. A fourth Tasklet/Errandimp/Bedrotte/Dawnle goal concept and Mendle repair tier V were generated only to preserve a regular grid and are intentionally not exported.
- Sheet B contains companion quest tiers I–III and Journey goal tiers I–III.
- The exact production prompts are stored beside this file as `dawnle-v1-sheet-a-prompt.txt` and `dawnle-v1-sheet-b-prompt.txt`.
- fal request IDs, prompt hashes, model, references, and source URLs are stored with the source renders in `tmp/imagegen/daily-rhythm-batch-v1/*.generation.json`.

The measured grid cuts and exact runtime mapping are stored in `dawnle-v1.json`.
