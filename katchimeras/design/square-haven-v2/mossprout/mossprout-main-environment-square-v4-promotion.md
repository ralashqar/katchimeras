# Mossprout main environment square v4

The user-supplied `mossprout-main-environment-square-v4-source.jpg` is the
approved production artwork. It is promoted without redesigning, recoloring,
relighting, warping, cropping, or repainting the island.

The built-in image-generation workflow was used for a strict background-only
key attempt. The shipped alpha master instead preserves the source JPEG RGB
pixels and removes only blue/cyan backdrop pixels connected to the canvas
border through `scripts/extract-haven-blue-background.py`.

The full supplied square canvas is preserved when creating the 1024px, 512px,
and 256px runtime tiers. Mossprout's resident anchor moves from 47% to 51% of
the island frame height so the separately rendered resident stands at the
center of the new circular stone plaza.
