# Glow currency art v3

Shared runtime asset: `assets/images/katchimeras/merge-world/ui/glow-swirl-v3.png`.

Edited v2 with built-in imagegen to preserve its curled flame silhouette while
replacing the white/cream center ring with a continuous sculpted amber-gold
swirl. Soft bevels, low texture detail, golden center bead, no surrounding effects.

Background removed using the project's FAL BiRefNet endpoint; packaged as a
512x512 transparent PNG and inspected against the game's sand background.
`GAME_CURRENCY_ART.coins` supplies this version to the shared Glow UI.
