# Merge World generated artwork

- `merge-board-base.webp` is the runtime 7x9 static board surface generated by
  `scripts/generate-merge-board-base.py`. It contains the borderless,
  rounded-cell checkerboard treatment in one native image.
- `merge-board-atlas.webp` is a legacy item review/contact sheet. It is not a
  board texture and must not be mounted by the Merge board.
- `mossprout-merge-core-atlas.webp` and
  `mossprout-merge-progression-atlas.webp` are shared packaging/review pages
  generated by `scripts/build-mossprout-merge-atlases.py`. Their frames are
  described by `mossprout-merge-atlas.json`; the 8 px gutters must be
  preserved when repacking. Native runtime currently loads the corresponding
  256 px individual WebPs so it never mounts a full atlas image per sprite.
- The Garden, Waterside, Keepsake, Wild Garden, and Memory Nursery toy-diorama
  sprites are sliced from the approved alpha sheets in
  `artifacts/mossprout-toy-items` by
  `scripts/package-mossprout-toy-items.py`.
